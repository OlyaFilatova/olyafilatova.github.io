# olyafilatova.github.io - Особистий вебсайт та інструменти

[GitHub Репозиторій](https://github.com/OlyaFilatova/olyafilatova.github.io)

Проєкт є монорепозиторієм, який містить вихідний код вебсайту, Chrome-розширення для збереження нотаток до сторінок, різноманітні інструменти для підготовки контенту та допоміжні сервіси.

Основна мета цього проєкту - зберігати мої нотатки та думки без додаткових витрат на хостинг. Тому я вирішила використовувати GitHub Pages на основі публічного репозиторію. Інструменти, які потребують додаткових обчислювальних ресурсів (наприклад, переклад), використовуються лише локально, а рішення для зберігання даних базуються або на сховищі браузера, або на статичному вмісті вебсайту.

## Основний стек технологій

**Мови програмування:** TypeScript, Python.

**Front-end:** React.js, Manifest V3.

**Back-end:** Nest.js, FastAPI.

**Інфраструктура:** Docker, docker-compose, GitHub Pages, GitHub Actions, монорепозиторій (pnpm, uv).

**Моделі:** Helsinki-NLP/opus-mt-en-uk, Helsinki-NLP/opus-mt-uk-en.

## Підпроєкти

### Вебсайт

Особистий вебсайт.

**Розгорнуто:** на GitHub Pages.

**Мова:** TypeScript.

**Фреймворки та бібліотеки:** React.js (Functional Components), html-react-parser, zod.

**Сховище:** IndexedDB, localStorage.

**Підтримує дві мови:** українську та англійську. Після перемикання мови обрана мова зберігається в кеші браузера.

**Сторінки:** головна сторінка, нотатки про джерела знань, проєкти, хронологія досвіду.

Контент сторінок зберігається в папках `assets` у файлах `.json` або `.html` та завантажується за потреби. Сторінки "Проєкти" та "Нотатки" використовують згенеровані індекс-об'єкти для отримання контенту. Вміст JSON-файлів перевіряється за допомогою бібліотеки zod.

Підготовка вебсайту перед розгортанням використовує інструменти `experience assemble`, `thoughts assemble` та `projects assemble`.

### Сервіси

#### Parse GitHub Issue

Парсить список посилань певного формату з GitHub Issue.

**Розгорнуто:** локально за допомогою Docker.

**Мова:** Python.

**Фреймворки та бібліотеки:** FastAPI, Pydantic, requests.

**Вимоги:** GitHub-токен із правом доступу **Read Issue**.

**Функціональність:** Приймає Issue URL, отримує його вміст через GitHub API та витягує список посилань із тексту.

Очікуваний формат тіла Issue:

- список посилань у вигляді чекліста;
- лише одне посилання в одному рядку;
- посилання має бути наприкінці текстового рядка.

#### Markdown to HTML

Перетворює Markdown-текст на HTML.

**Розгорнуто:** локально за допомогою Docker.

**Мова:** TypeScript.

**Фреймворки та бібліотеки:** Nest.js, markdown-it.

**Функціональність:** Приймає Markdown-текст і повертає HTML-результат.

#### Translate

Перекладає список текстів з української на англійську або з англійської на українську.

**Розгорнуто:** локально за допомогою Docker.

**Мова:** Python.

**Фреймворки та бібліотеки:** FastAPI, pydantic, torch, transformers.

**Вимоги:** Пристрій, здатний запускати моделі `Helsinki-NLP/opus-mt-*`.

**Функціональність:**

- Під час першого запуску попередньо завантажує моделі.
- Приймає напрямок перекладу та список рядків.
- Повертає список перекладених рядків у тому самому порядку, що й у вхідному списку.

### Chrome-розширення

#### Page Notes

Локальне зберігання нотаток, згруповано за сторінками.

Chrome-розширення побудоване на основі репозиторію https://github.com/OlyaFilatova/page-notes.

Версію розширення в цьому репозиторії розширено підтримкою сервісів, зокрема сервісу Parse GitHub Issue.

**Розгорнуто:** локально як unpacked extension.

**Мова:** TypeScript.

**Фреймворки та бібліотеки:** React.js.

**Сховище:** IndexedDB, localStorage.

**Вимоги:** Локально запущений сервіс Parse GitHub Issue на порту 8000.

**Функціональність:** Під час відкриття Side Panel розширення відображається форма для поточної сторінки. Нотатки можна зберігати через форму або безпосередньо зі сторінки: 1. виділити текст, 2. натиснути кнопку **Save Note**, яка з'являється поруч із виділенням. Якщо значення текстового поля змінюється, воно автоматично зберігається в кеші браузера з прив'язкою до URL поточної сторінки.

Нижче блоку поточної сторінки відображаються раніше збережені нотатки з інших сторінок. Нотатки можна видаляти. Список підтримує пошук і пагінацію по 10/25/50 сторінок на сторінку. Нотатки зберігаються в IndexedDB.

Кнопка **Set current GitHub issue** відкриває форму, за допомогою якої можна отримати список посилань із GitHub Issue. Посилання відображаються під формою, згруповані за статусами:

- **planned** - прапорець у чеклісті Issue не встановлений;
- **in progress** - посилання відповідає умовам статусу *planned*, але для нього вже існують нотатки в розширенні;
- **done** - прапорець у чеклісті Issue встановлений.

Кнопка **Export JSON** експортує сторінки та їхні нотатки у форматі JSON. Зазвичай сторінки експортуються під власними URL. Якщо налаштовано поточний GitHub Issue, усі сторінки, перелічені в ньому, групуються та експортуються під URL цього Issue.

Кнопка **Clear all** після підтвердження очищає всі збережені нотатки з бази даних браузера.

### Скрипти

#### experience assemble

**Мова:** TypeScript.

**Функціональність:** Зчитує файли з папки `data/experience` та генерує файл `website/data/experience.ts`, який використовується для завантаження сторінки "Хронологія досвіду".

#### thoughts assemble

**Мова:** TypeScript.

**Функціональність:** Зчитує файл `list.txt` із папки `data/knowledge-sources`. Завантажує дані з кожної папки, переліченої у файлі, оновлює поле `updatedAt` на основі дати файлу в Git для `content.json`, зберігає файли до папки `website/assets/knowledge-sources`. Оновлює файл `website/data/knowledge-sources-index.ts`: збільшує `bustCache` та індексує файли за статусом, типом, доступом і категоріями.

#### projects assemble

**Мова:** TypeScript.

**Функціональність:** Зчитує файли з папки `data/projects` для кожної мовної версії вебсайту. Перетворює файли з формату Markdown у HTML. Зберігає нові файли в папці `website/assets/projects`. Генерує індекс у файлі `website/data/projects-index.ts`.

#### format notes

Перекладає нотатки, експортовані з розширення Page Notes, та готує їх для вебсайту.

**Мова:** Python.

**Бібліотеки:** requests.

**Передумови:** Експортовані файли з розширення Page Notes.

**Вимоги:** Локально запущений сервіс Translate на порту 8001.

**Функціональність:** Зчитує файли з папки `scripts/pytools/notes`. Вважає, що весь вміст записаний англійською мовою. Для кожної сторінки надсилає нотатки до сервісу Translate та зберігає результат в окрему папку `{file_idx}-{page_idx}` у каталозі `scripts/pytools/formatted`. Результат розділяється на файли `meta.json` та `content.json`. `meta.json` містить метадані (наприклад, URL), а `content.json` - список перекладених нотаток.

Після вичитки перекладів файли переміщуються до папки `data/knowledge-sources`.
